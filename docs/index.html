导梦把一句灵感，导成一条可确认的视频生产线

面向缺少编剧与导演能力的普通创作者，WorkflowEngine 按顺序调度六个阶段 Agent，将创意转换成剧本、角色与场景、分镜、参考图、视频片段和最终成片。

当前实现：集中式顺序编排、共享 Session、阶段级人工确认、资产版本保留与局部重生成。
